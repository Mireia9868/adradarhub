How to check the ads your competitors are running

Every major ad platform now publishes what advertisers are running. The data is free — the hard part is knowing which library answers which question, and where each one silently stops being useful.

Last updated · 2026-10-28

Why ad transparency libraries exist

Regulators pushed platforms to disclose political and, later, commercial advertising. The result is a set of public libraries you can query by advertiser name, keyword or region. For a marketer, this is the cheapest competitive research available: you see the actual creative, the landing page, and often how long an ad has been running.

Two caveats shape everything below. First, coverage is uneven — Meta is close to exhaustive, TikTok's public view is not. Second, these libraries are built for accountability, not for analysis: no performance data, no spend by default, limited history.

Meta Ad Library

The most complete free source. Search by page name, browse by country, filter by ad category. For commercial ads you get the creative, the start date, the platforms it runs on, and the landing page. Political and issue ads additionally expose spend ranges and impressions.

What it is good for: seeing how many creatives a competitor rotates, how often they refresh, and whether a winning angle has been running for months.

Where it stops: no targeting, no spend for commercial ads, and search is by advertiser rather than by product or angle. Bulk analysis needs the Ad Library API, which requires an access token and identity verification — that is exactly the gate our Meta connector sits behind.

Google Ads Transparency Center

Search any verified advertiser and see the ads they have served across Search, Display, and YouTube. Google shows the creative, the format, the region, and the first and last date the ad was seen.

What it is good for: capturing search ad copy and display creative in a specific market, and spotting which offers a competitor keeps re-running.

Where it stops: Google exposes creative, not keywords. There is no public API for the transparency center in the way Meta has one, so any tool — including this one — needs to go through a connector or a licensed data provider, and result depth is bounded by what that path returns.

Microsoft Ad Library

Microsoft publishes a public Ad Library API covering ads served on the Microsoft Advertising network, which includes Bing search and syndicated placements. You query by advertiser, and results include the ad copy and the dates it was live.

What it is good for: B2B and high-intent search markets, and for checking whether a competitor has expanded beyond Google.

Where it stops: coverage is smaller than Google's and creative formats are mostly text. Access still requires an approved API key.

YouTube and TikTok

YouTube: ad creative often also appears in the Google Ads Transparency Center, but to find the organic video a competitor is amplifying you need the YouTube Data API — search by channel or keyword, then read titles, descriptions, durations and view counts. It tells you what they are pushing, not what they are paying.

TikTok: TikTok has no public ad library API equivalent to Meta's. Its Creative Center shows top ads and trend signals but is not a searchable archive per advertiser. Anything deeper requires a licensed third-party data provider, which is why this site's TikTok source is explicitly marked as third-party rather than official.

A repeatable weekly workflow

  1. Pick 3–5 competitors, not twenty. Include one direct rival, one adjacent category, and one player winning in a market you are entering.
  2. Scan weekly, same day. Ad libraries are snapshots; the signal is in the delta — new creatives, killed creatives, offers that keep running.
  3. Log start dates. An ad running 90+ days is either a winner or abandoned budget. Cross-check with the landing page before assuming it is a winner.
  4. Teardown the hook, not the whole ad. Record the first three seconds, the promise, the proof, and the CTA separately so the pattern is reusable.
  5. Turn it into a brief. A finding that stays in a spreadsheet changes nothing. Write the next creative as a concrete assignment with structure, claims allowed, and claims banned.
