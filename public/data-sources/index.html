Data sources, coverage and limits

An ad intelligence tool is only as trustworthy as its provenance. This page lists every source we query, whether it is currently live, and where the data stops being authoritative.

Last updated · 2026-10-28

Why some sources are in demo mode

Two of the libraries we query are not open by default. Meta's Ad Library API requires a token tied to a verified identity, and Google's transparency data has no anonymous public endpoint. Until those credentials are issued and configured server-side, the site runs those connectors in demo mode and labels the output.

We would rather show a labelled demo than a quietly fabricated number. If a source you need is still in demo, the data-source panel inside the app tells you exactly which environment variable is missing.

What this data cannot tell you

  • No spend figures for commercial ads. Political ads disclose ranges; commercial ones do not.
  • No performance metrics. CTR, CVR, CPA and ROAS belong to the advertiser. Any tool claiming to show a competitor's ROAS is inferring, not measuring.
  • No targeting details. You see the creative, not the audience, bid or budget.
  • Snapshot history. Libraries show current state and dates, not a full day-by-day archive.
  • Deduplication is heuristic. The same creative reused across campaigns can appear more than once.

Our iteration module works around the last gap: you import your own campaign CSV, and the platform metrics come from your account rather than being guessed from a competitor's public footprint.

Freshness and quota

Scans are executed on demand — nothing is pre-crawled and cached, so a result reflects the moment you asked for it. Free accounts get ten pulls per day, resetting at midnight UTC+8. Each scan counts once regardless of how many platforms you select; image generation and text generation draw from the same daily pool.

Analytics pulls (Search Console / GA4) run against the service account you configure and are limited by Google's own API quotas, not by us.
