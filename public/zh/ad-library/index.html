怎么查竞品正在投的广告

主流广告平台现在都公开投放中的广告。数据本身免费，难的是知道哪个库能回答哪个问题，以及每个库在什么地方开始失效。

最后更新 · 2026-10-28

广告透明度库是怎么来的

监管推动平台披露广告主身份，最初针对政治广告，后来扩展到商业广告。结果是每个大平台都有一个可以按广告主、关键词或地区查询的公开库。对投放同学来说，这是成本最低的竞品研究方式：能看到真实素材、落地页，通常还能看到一条广告跑了多久。

有两个前提决定了下面所有内容。第一，覆盖度并不均匀——Meta 接近全量，TikTok 的公开视野远没有那么多。第二，这些库是为"问责"设计的，不是为"分析"设计的：没有效果数据，默认没有花费，历史深度也有限。

Meta 广告库

免费来源里最完整的一个。可以按主页名称搜索、按国家浏览、按广告类别筛选。商业广告能看到素材、开始投放日期、投放版位和落地页；政治与议题广告额外公开花费区间和曝光量。

适合看什么：竞品同时跑多少条素材、多久换一次、某个打法是不是已经跑了几个月。

边界在哪：商业广告没有定向信息、没有花费；搜索是按广告主而不是按产品或卖点。要做批量分析得用 Ad Library API，需要 access token 和身份验证——我们的 Meta connector 就卡在这道门上。

Google 广告透明度中心

搜索任意已验证广告主，能看到它在搜索、展示和 YouTube 上投放的广告。Google 会给出素材、格式、地区，以及首次和最后一次出现的日期。

适合看什么：抓某个市场的搜索广告文案和展示素材，判断竞品在重复投哪些 offer。

边界在哪：Google 公开的是创意，不是关键词。透明度中心没有 Meta 那种公开 API，所以任何工具（包括这个站）都要走 connector 或持牌数据源，能拿到多深取决于那条链路的返回。

Microsoft 广告库

Microsoft 提供公开的 Ad Library API，覆盖 Microsoft Advertising 网络上的广告，包括 Bing 搜索和联盟版位。按广告主查询，返回广告文案和投放日期。

适合看什么：B2B 和高意图搜索市场，以及判断竞品是否已经走出 Google。

边界在哪：覆盖小于 Google，素材以文字为主。调用依然需要申请通过的 API key。

YouTube 与 TikTok

YouTube：广告素材通常也能在 Google 透明度中心看到，但要找到竞品正在放大的自然视频，需要用 YouTube Data API：按频道或关键词搜索，再读标题、描述、时长和播放量。它告诉你对方在推什么，不告诉你对方花了多少钱。

TikTok：没有与 Meta 对等的公开广告库 API。Creative Center 会展示热门广告和趋势信号，但不是一个可按广告主检索的归档。要更深的数据只能接持牌第三方数据源——所以本站的 TikTok 数据源明确标注为第三方，而不是官方。

一套可复用的每周流程

  1. 选 3–5 个竞品，不要二十个。一个直接对手、一个相邻品类、一个在你正要进的市场里跑得不错的玩家。
  2. 每周固定同一天扫一次。广告库是快照，信号在变化量里：新上的素材、被下掉的素材、一直没停的 offer。
  3. 记录开始日期。跑了 90 天以上的广告，要么是赢家，要么是没人管的预算。先看落地页再判断。
  4. 拆 hook，不要拆整条广告。前 3 秒、承诺、证明、CTA 分开记，模式才能复用。
  5. 落成 brief。只留在表格里的发现不会改变任何事。把下一条素材写成明确任务：结构、可用卖点、禁用话术。

这个站存在的意义就是把第 2–5 步压缩：一次域名扫描并行拉各库，迭代模块把结果变成素材团队能直接开拍的 brief。
