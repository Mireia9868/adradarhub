数据源、覆盖范围与限制

广告情报工具的可信度等于它的数据出处。这一页列出我们调用的每个来源、当前是否实采、以及数据在什么地方不再权威。

覆盖总览

下面的状态反映线上部署，connector 变更时会同步更新。实采 表示结果来自平台自己的 API 或公开接口。演示 表示该接口尚未配好凭证，界面展示的是示例数据——界面上会明确标注，避免把演示结果当成真实结果。

为什么有些源是演示模式

我们调用的库里有两个默认不开放。Meta 的 Ad Library API 需要绑定已验证身份的 token；Google 的透明度数据没有匿名的公开接口。在这些凭证下发并配置到服务端之前，站点会让对应 connector 跑在演示模式，并给输出打标。

我们宁愿显示一个标注清楚的演示，也不给一个悄悄编造的数字。如果你需要的源还在演示模式，应用内的数据源面板会准确告诉你缺哪个环境变量。

这些数据告诉不了你什么

  • 没有花费数据（商业广告）。政治广告会公开区间，商业广告不会。
  • 没有效果指标。CTR、CVR、CPA、ROAS 属于广告主自己。任何声称能看到竞品 ROAS 的工具都是在推断，不是在测量。
  • 没有定向细节。你能看到素材，看不到受众、出价和预算。
  • 历史是快照。库展示的是当前状态和日期，不是逐日归档。
  • 去重是启发式的。同一条创意在不同 campaign 里复用，可能重复出现。

迭代模块就是绕开最后一个缺口：你自己导入投放数据 CSV，效果指标来自你的账户，而不是从竞品的公开足迹里猜。

更新频率与额度

扫描是按需执行的，没有预抓取和缓存，所以结果反映的是你发起查询那一刻。免费账户每天 10 次，UTC+8 零点重置。一次扫描计一次，和你选了几个平台无关；生成图片和生成文案共用同一个每日额度。

站点数据分析（Search Console / GA4）跑在你配置的服务账号上，受 Google 自己的 API 配额限制，不受我们限制。
